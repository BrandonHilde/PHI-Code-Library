# BMP Suite 2.8

Image files from Jason Summers's BMP Suite, version 2.8 (2023-11-28),
<https://entropymine.com/jason/bmpsuite/>. Its readme says:

> Image files generated by this program are not covered by this license, and are in the public domain
> (except for the embedded ICC profiles).

So the two files with embedded ICC profiles, `q/rgb24prof.bmp` and `q/rgb24prof2.bmp`, are left out.
Nothing else is changed. `g` is what the suite calls good, `q` questionable, `b` bad, and `x` related
formats. Its descriptions of each file are in its `html/bmpsuite.html`.
