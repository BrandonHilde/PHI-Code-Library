# What came from elsewhere

weblib's code is its own: nothing in it was copied from another project, and nothing from GPL code
(checked 2026-11-07, when it moved here). What did come from elsewhere is test data, and tables
generated from public data. Each keeps its own license.

## Test data

Read by the tests, never built into a program.

| Where | What | From | License |
|---|---|---|---|
| `tests/html5lib/tree-construction/` | HTML tree-construction tests | web-platform-tests/wpt, commit `bccd09e` | 3-clause BSD: `tests/html5lib/LICENSE-wpt.md` |
| `tests/html5lib/tokenizer/` | HTML tokenizer tests | html5lib/html5lib-tests, commit `c5495c5` | MIT: `tests/html5lib/LICENSE` |
| `tests/html5lib/tokenizer-flat/` | the same, flattened by `tools/web/html_tokenizer_tests.py` | | as above |
| `tests/css-parsing-tests/` | CSS syntax tests | Simon Sapin's css-parsing-tests | public domain (CC0): `tests/css-parsing-tests/LICENSE` |
| `tests/js/test262self/harness/` | test262's `assert.js`, `sta.js` and `doneprintHandle.js` | tc39/test262, commit `d115437` | BSD: its `LICENSE` beside them |
| `tests/test262/` (not in git) | test262 | tc39/test262, commit `d115437`, fetched by `tools/web/fetch_test262.py` | BSD |
| `tests/js/unicode/DerivedCoreProperties.txt` | which code points are identifier characters | Unicode 18.0 | Unicode License v3: `tests/js/unicode/LICENSE` |

The rest of `tests/` (`tests/js/*.js`, `tests/page/`) was written for weblib.

## Tables in the library

Generated by the scripts in `tools/web/`, and built into every program that uses weblib.

| File | What | From |
|---|---|---|
| `html/entities.phi` | HTML's named character references | the HTML Standard's list (WHATWG, CC BY 4.0), as Python's `html.entities.html5` has it |
| `html/tags.phi` | what the parser knows about each element | written from the HTML Standard's parsing sections |
| `js/unicode.phi` | identifier characters | Unicode's `DerivedCoreProperties.txt` (Unicode License v3) |
| `js/casemap.phi` | case mapping and general categories | Python's own Unicode database (Unicode License v3) |
| `css/tables.phi` | CSS properties and their grammars | written from the CSS specifications |
